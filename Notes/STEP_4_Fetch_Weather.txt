STEP 4: Fetch Weather Data from API
=====================================

GOAL: Make API calls to get real weather data

TASKS:
------
1. Create a state variable to store weather data
2. Create an async function to fetch weather data
3. Use fetch() or axios to call the API
4. Parse the JSON response
5. Update the weather state with the data
6. Console.log the weather data to see what you get

CONCEPTS YOU'LL LEARN:
----------------------
- Async/await
- fetch API
- Working with JSON
- API responses
- Promise handling

CODE STRUCTURE:
---------------
const [weatherData, setWeatherData] = useState(null);

const fetchWeather = async () => {
  const API_KEY = import.meta.env.VITE_WEATHER_API_KEY;
  const url = `https://api.openweathermap.org/data/2.5/weather?q=${city}&appid=${API_KEY}&units=metric`;

};
