BONUS FEATURES: Level Up Your Weather App!
===========================================

Once you've completed all 7 steps, try adding these features:

1. SEARCH ON ENTER KEY
   ----------------------
   - Allow users to press Enter to search
   - Add onKeyDown handler to input
   - Check if key is 'Enter' and trigger search

2. DEFAULT CITY ON LOAD
   ----------------------
   - Use useEffect to load a default city on app start
   - Fetch weather for "London" or user's location
   - Runs once when component mounts

3. SEARCH HISTORY
   ----------------
   - Store last 5 searched cities in state
   - Display as clickable chips/buttons
   - Save to localStorage
   - Quick re-search from history

4. TEMPERATURE UNIT TOGGLE
   -------------------------
   - Add toggle button for Celsius/Fahrenheit
   - Convert temperature based on selection
   - Formula: °F = (°C × 9/5) + 32

5. 5-DAY FORECAST
   ----------------
   - Use different API endpoint:
     api.openweathermap.org/data/2.5/forecast
   - Display weather for next 5 days
   - Show in a horizontal card layout

6. WEATHER BACKGROUND
   --------------------
   - Change background color/image based on weather
   - Sunny = yellow/bright
   - Rainy = blue/grey
   - Cloudy = grey
   - Snowy = white/blue

7. GEOLOCATION
   -------------
   - Add "Use My Location" button
   - Use navigator.geolocation API
   - Fetch weather for user's coordinates

8. FEELS LIKE & MORE DETAILS
   ---------------------------
   - Display "Feels Like" temperature
   - Add pressure, visibility
   - Sunrise/sunset times
   - Min/max temperature

9. RESPONSIVE DESIGN
   -------------------
   - Make it mobile-friendly
   - Use media queries
   - Test on different screen sizes

10. DARK MODE
    ----------
    - Add dark/light theme toggle
    - Save preference to localStorage
    - Use CSS variables for theming

CHALLENGE YOURSELF:
-------------------
Try implementing these without looking up the solution first!
Each feature will teach you new React concepts and patterns.

GOOD LUCK! 🌤️
