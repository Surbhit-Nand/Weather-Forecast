STEP 3: Set Up Weather API
============================

GOAL: Get a free API key and prepare to fetch weather data

TASKS:
------
1. Sign up for a free API key at: https://openweathermap.org/api
   - Create account
   - Go to "API keys" section
   - Copy your API key

2. Create a .env file in the root directory (next to package.json)
3. Add your API key to .env:
   VITE_WEATHER_API_KEY=your_api_key_here

4. Add .env to .gitignore (should already be there)

5. Test accessing the API key in your code:
   console.log(import.meta.env.VITE_WEATHER_API_KEY)

CONCEPTS YOU'LL LEARN:
----------------------
- Environment variables
- API authentication
- Keeping secrets secure
- .env files in Vite

API ENDPOINT:
-------------
https://api.openweathermap.org/data/2.5/weather?q={city}&appid={API_KEY}&units=metric

IMPORTANT NOTES:
----------------
- Never commit your .env file to GitHub!
- API key may take a few minutes to activate
- Free tier allows 60 calls per minute

HINT:
-----
In Vite, environment variables must start with VITE_ to be accessible!
Use import.meta.env.VITE_YOUR_VAR_NAME to access them.
